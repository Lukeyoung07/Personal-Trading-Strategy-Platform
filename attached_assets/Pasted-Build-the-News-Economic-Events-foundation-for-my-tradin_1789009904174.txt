Build the News & Economic Events foundation for my trading platform.

This task is ONLY for the News & Economic Events foundation.

GOAL:

Create a dedicated News & Economic Events section that allows the application to show upcoming and recently released economic events that could affect financial markets.

The system should classify events as:

- HIGH IMPACT
- MEDIUM IMPACT
- LOW IMPACT

Each event should contain, where available:

- Event name
- Date
- Time
- Impact level
- Country/region
- Currency
- Affected markets
- Previous value
- Forecast/consensus
- Actual value
- Release status

MARKET IMPACT:

The system should associate events with the markets they are relevant to.

Examples:

US CPI
→ USD
→ Gold
→ US indices
→ Forex

FOMC interest-rate decision
→ USD
→ Gold
→ US indices
→ Treasury-related markets

UK CPI
→ GBP
→ UK indices
→ GBP forex pairs

Do not hard-code incorrect market relationships.

Use a structured impact mapping that can be expanded later.

NEWS PAGE:

Create a dedicated News / Economic Calendar page.

It should allow users to:

- View today's events
- View upcoming events
- View recently released events
- Filter by impact
- Filter by country/region
- Filter by currency
- Filter by affected market
- Search events

Make HIGH IMPACT events visually obvious.

For example:

🔴 HIGH IMPACT
US CPI
USD
14:30

🟡 MEDIUM IMPACT
UK Retail Sales
GBP
07:00

🟢 LOW IMPACT
... 

Do not rely on colour alone; include the text label as well.

EVENT TIMING:

Clearly distinguish:

- Upcoming
- Released
- Live/releasing, if the data source provides this state

Show a countdown to upcoming events where reliable timing data is available.

Do not create fake countdowns or fake release times.

DATA SOURCE:

Create a provider-neutral news/economic-calendar service architecture.

Do NOT hard-code the system to a single provider.

Do NOT assume a specific news provider unless an existing configured provider is already available.

The architecture should allow a real economic-calendar/news provider to be connected later.

If no real news provider is currently connected, show an honest empty/unavailable state.

Do NOT generate fake events or fabricated economic data.

However, do NOT build the future trade-warning functionality yet.

Keep the news system separate from the existing Strategy Monitoring Engine.

Add a clear empty state if no real data source is connected.

For example:

"No economic calendar data is currently connected."

Do not populate the page with fake sample events.
