2. BUILDER
==================================================

Each condition should preserve:

- canonical concept ID
- canonical name
- direction
- timeframe
- typed parameters
- relationship metadata
- execution status
- validation state

For example:

- FVG must remain FVG.
- FVG Retest must remain FVG Retest.
- Displacement must remain Displacement.
- Breakout must remain Breakout.
- EMA Cross must remain EMA Cross.

Bullish Breakout
Bearish Breakout

Do not create fake unsupported concepts such as "Short Breakout".

6. EXECUTABLE VS REVIEW REQUIRED
==================================================

Create one authoritative compatibility decision.

A concept is:

Otherwise:

REVIEW_REQUIRED

with an exact reason.

The compatibility checker must run against the FINAL reconciled structured strategy.

Never calculate Review Required from:
- raw model output
- generated prose
- unfiltered model conditions
- previous session state
- unrelated concepts

If every final requested condition is executable:

Review Required = EMPTY.

Do not display Review Required.

If a requested concept is unsupported:

show only that requested unsupported concept.

Do not show unrelated concepts.
