The issue is specifically that most events currently display:

"Not classified"

because the existing public sources do not provide trader-style impact ratings.

GOAL:

Add a transparent deterministic impact-classification system that can classify economic events based on the event type/name and structured metadata already available.

Do NOT use AI.

Do NOT use a paid API.

Do NOT invent provider data.

Do NOT pretend the source supplied an impact rating when it did not.

IMPORTANT:

The application must clearly distinguish between:

1. PROVIDER-SUPPLIED IMPACT
2. APPLICATION-CLASSIFIED IMPACT
3. NOT CLASSIFIED

If the provider supplies an impact rating, preserve it.

If the provider does not supply one, the application may calculate its own classification using the deterministic rules below.

DISPLAY:

Show the source of the classification.

For example:

Impact: HIGH
Classification: Application rule

or:

Impact: HIGH
Classification: Provider

or:

Impact: NOT CLASSIFIED
Classification: Not enough information

RULES:

Create a maintainable event-impact rule registry.

The rules should match event types rather than blindly matching arbitrary words.

Start with the following conservative categories.

HIGH IMPACT:

- Central-bank interest-rate decisions
- FOMC rate decisions
- ECB monetary-policy decisions
- BoE monetary-policy decisions
- CPI / inflation releases
- Core CPI
- Non-Farm Payrolls / NFP
- Major employment reports
- GDP major releases
- PCE inflation
- Core PCE
- Major unemployment-rate releases
- Major central-bank policy statements when clearly identified as monetary-policy decisions

MEDIUM IMPACT:

- Retail Sales
- PMI
- Manufacturing PMI
- Services PMI
- Industrial Production
- Durable Goods
- Housing data
- Consumer Confidence
- Producer Price Index / PPI
- Trade Balance
- Employment reports that are not major headline releases

LOW IMPACT:

- Minor surveys
- Secondary economic indicators
- Small/less influential releases
- Administrative/statistical releases where appropriate

IMPORTANT:

These rules are only a starting classification system.

Do not claim that HIGH means the market will definitely move.

Impact means the event is potentially important to traders, not that the market will rise or fall.

UNCLASSIFIED:

If the event name/type cannot be confidently matched to a rule:

Impact: NOT CLASSIFIED

Do not guess.

SOURCE:

For every classified event, retain:

- Source
- Original provider impact if available
- Application classification
- Classification reason/rule

Example:

US CPI

Impact: HIGH
Source: Federal/official source
Classification: Application rule
Reason: CPI is classified as a high-importance inflation release.
