==================================================
1. RESULTS SUMMARY
==================================================

When a backtest completes successfully, show a clear results page/section.

Display:

- Strategy name
- Exact strategy version
- Instrument
- Timeframe
- Date range
- Candles processed
- Total trades

Main performance statistics:

- Winning trades
- Losing trades
- Win rate
- Total P/L
- Average winning trade
- Average losing trade
- Largest winning trade
- Largest losing trade
- Maximum drawdown
- Profit factor

If there are zero trades:

Show:

"No trades found for this strategy and period."

Do not display misleading performance statistics.

==================================================
2. PROFIT / LOSS
==================================================

Calculate all statistics from the actual stored backtest trades.

Do NOT create separate calculations using different trade data.

The dashboard must agree with the stored backtest trades.

For example:

Total P/L must equal the sum of all simulated trade P/L values.

Win rate must equal:

winning trades / total completed trades

Do not include incomplete trades in completed-trade statistics unless explicitly documented.

==================================================
3. EQUITY CURVE
==================================================

Add a simple equity curve.

The curve must be generated from the actual simulated backtest trades.

It should show how the simulated account balance changed throughout the historical period.

Use the existing backtest starting-balance configuration if one already exists.

If no starting balance exists in the current system, use the simplest appropriate implementation and clearly label the assumption.

Do NOT invent broker fees or slippage.

If fees/slippage are not included, state:

"Fees and slippage are not included."

4. DRAWDOWN
==================================================

Calculate maximum drawdown from the actual equity curve.

Display the result clearly.

14. PERFORMANCE ACCURACY
==================================================

All displayed statistics must be calculated from the stored simulated trades.

The following must remain consistent:

Trade count
=
number of stored completed trades

Winning trades
=
number of profitable trades

Losing trades
=
number of losing trades

Win rate
=
winning trades / completed trades

Total P/L
=
sum of trade P/L

Maximum drawdown
=
maximum peak-to-trough decline in the calculated equity curve

Do not round intermediate calculations in a way that changes the final result.
