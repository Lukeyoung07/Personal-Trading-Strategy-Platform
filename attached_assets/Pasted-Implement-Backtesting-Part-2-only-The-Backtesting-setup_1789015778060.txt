==================================================
1. USE REAL HISTORICAL DATA
==================================================

Use the existing Market Data Service and genuine historical OHLC candle data from BiQuote.

Do NOT:

- Create fake candles
- Fabricate prices
- Interpolate missing candles
- Duplicate candles
- Stretch candles
- Generate placeholder results

Use the selected:

- Instrument
- Timeframe

- End date

from the Backtesting setup.

If sufficient historical data is unavailable, return a clear error instead of producing misleading results.

==================================================
2. EXACT STRATEGY VERSION
==================================================

Use the exact strategy version selected by the user.

Do not automatically use the latest version.

The backtest must use the selected version's existing:

- Conditions
- Entry rules
- Exit rules
- Stop-loss rules
- Take-profit rules
- Reset rules
- Risk settings

Do NOT create a second unrelated strategy system.

Reuse existing strategy definitions/logic wherever possible.

==================================================
3. CHRONOLOGICAL EVALUATION
==================================================

Process historical candles strictly from oldest to newest.

For every candle:

1. Evaluate the strategy using only information available at that point.
2. Determine whether the strategy conditions are met.
3. Process entries according to the strategy.
4. Manage any open simulated position.
5. Process exits according to the strategy.
6. Record completed trades.
7. Continue to the next candle.

IMPORTANT:

Prevent look-ahead bias.

Never use future candles or future prices to determine an earlier decision.

Do not use information from a candle before it would have become available according to the strategy's evaluation rules.

==================================================
4. SIMULATED TRADES
==================================================

When the strategy produces a valid historical entry, create a simulated trade.

Record:

- Strategy ID
- Exact strategy version ID
- Instrument
- Timeframe
- Entry timestamp
- Entry price
- Direction
- Stop-loss when applicable
- Take-profit when applicable
- Exit timestamp
- Exit price
- Profit/loss
- Entry reason
- Exit reason

These are BACKTEST trades only.

Do NOT add them to the real Trade Journal.

==================================================
5. EXECUTION ASSUMPTIONS
==================================================

Because the backtest uses OHLC candle data rather than tick-by-tick historical data:

- Clearly define the execution convention.
- Do not claim tick-level accuracy.
- Do not assume an impossible entry price using information that was only known after the decision.

If the strategy generates a signal on a completed candle, use a consistent historical execution rule that does not introduce look-ahead bias.

Store the execution convention with the backtest.

==================================================
6. STOP LOSS / TAKE PROFIT
==================================================

If the selected strategy version contains stop-loss and/or take-profit rules, simulate them using the historical OHLC data.

If both stop-loss and take-profit could have been reached within the same candle and the OHLC data cannot determine which happened first:

DO NOT guess.

Use a clearly defined conservative/neutral handling rule and document it in the backtest assumptions.

Do not pretend candle data provides intrabar ordering when it does not.

==================================================
7. BACKTEST RESULT
==================================================

After processing the historical period, save a completed backtest record containing:

- Strategy
- Exact strategy version
- Instrument
- Timeframe
- Start date
- End date
- Number of candles processed
- Number of trades
- Completion status
- Execution assumptions
- Created timestamp

Also save the simulated trades associated with that backtest.

==================================================
8. ZERO TRADES
==================================================

Do not create fake results.

Return a successful backtest with:

"0 trades found for this strategy and period."

The backtest should still record the selected strategy, version, instrument, timeframe and period.
