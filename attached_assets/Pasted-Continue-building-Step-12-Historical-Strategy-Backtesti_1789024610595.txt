==================================================
CHRONOLOGICAL BACKTESTING
==================================================

Process historical candles strictly from oldest to newest.

For each candle:

1. Evaluate the strategy using only information available at that point in time.
2. Evaluate the strategy conditions.
3. Determine whether an entry should occur.
4. Manage any existing simulated position.
5. Determine whether an exit occurs.
6. Record completed trades.
7. Continue to the next candle.

IMPORTANT:

Prevent look-ahead bias.

Never use future candles to make decisions about earlier candles.

Never use future prices to determine an earlier entry or exit.

Do not use information from a candle before that information would have been available.

==================================================

- Exit reason

These are simulated backtest trades.

Do NOT add them to the user's real Trade Journal.

==================================================
EXECUTION ASSUMPTIONS
==================================================

Historical data is OHLC candle data rather than tick-by-tick data.

Therefore:

- Do not claim tick-level execution accuracy.
- Do not use impossible entry prices.
- Do not use future information.
- Use a consistent execution convention.

If the strategy produces a signal on a completed candle, use a clearly defined execution convention that avoids look-ahead bias.

Store the execution convention with the backtest.

Show the user a simple explanation of the convention in the results.
